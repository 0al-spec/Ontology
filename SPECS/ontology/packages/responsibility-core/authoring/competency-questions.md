# Responsibility core competency questions

These questions assess the vocabulary/mapping, not executed responsibility cases.

| Question | Contract / expected interpretation | Evidence boundary |
|---|---|---|
| Can the car/community be actor while a human is anchor? | Yes; actor is an event-core role and anchor is selected separately. | Human subtype construction and attributed+ remain required in the mapped profile. |
| Is actor automatically the duty bearer? | No; relationDutyBearer is explicit. | Current R3 scope has no independent duty-bearer slot; separate alignment is not certified by it. |
| Does a relation end when the originator stops acting? | Not necessarily; continuation/termination conditions are separate. | No relation persistence evaluator is implemented. |
| Does no payment statement prove omission? | No; performed- must have explicit support in the same scope. | No unknown-to-negative conversion or source inference is implemented. |
| What if performance has both signs? | Keep both supports; mapped clear-premise gate rejects a definite omission. | This follows the pinned source definition; no full Belnap calculus is claimed. |
| Does an operator claim become a citation? | No; OperatorSupport has author/rationale and a different type from CitedSupport. | Object schemas do not check relations or semantic citation relevance. |
| Can one certificate target another event? | No under the bound mapping; all literal arguments and registry context must match. | Package compilation alone does not construct or verify a certificate. |
| Does an unused support deletion invalidate every result? | Not necessarily; retained mapped used facts/rules can preserve a Tree. | Source provenance remapping and Profile.check are separate checks. |
| Can an opposite added fact invalidate admission? | Yes, even if Tree.verify remains true. | Recheck the opposition-sensitive profile, not only the Tree. |
| Does breachRecorded impose a sanction? | No; ResponseRule/ResponseCandidate need their own trigger and authority. | R3 has no generic sanction or response-rule model. |
| Can source-only parking create a registered physical record? | Not without actual supplied states; keep a candidate. | v1 cannot detect invented snapshots; ONT-047 owns stronger provenance. |
