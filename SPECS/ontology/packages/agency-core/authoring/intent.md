# Intent — Generic Agency Core

User request 2026-10-28: implement maximally basic concepts in Ontology so that
NormLab can build domain-specific normative models on them, rather than putting
criminal-law classifications into the generic ontology.

Preserve the broad actor: a person, community, AI, machine or natural phenomenon
may occupy the existing Entity actor role. This does not assign psychology to all
entities. Unconscious motivation is possible as an attribution, but unknown
motivation is not automatically unconscious. Psychological inapplicability is an
explicit scoped claim, not a default from type or missing evidence.

Reuse existing Motive/MotivationHypothesis. Add neutral proposition content,
actor/view context and independent claims for awareness, goal, intention,
anticipation and outcome attitude. Each claim has its own support and workflow.
Neither goals nor forecasts establish physical states, actual consequences or
causation. Source-only candidates may stay source-only indefinitely.

Deliver compiler IR/SDK and an explicit bounded reference-envelope validator.
Its caller supplies a validated reference index. Reference checks are not graph
authentication, semantic relevance, mental truth or a universal normative engine.
Keep all existing versions/profiles/reports immutable. No paid inference required.
