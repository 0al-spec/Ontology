# Motive — actor-scoped prompting reason

The user requests Motive in the ontology: a reason prompting an actor's action
or omission leading to a consequence. The user explicitly confirms any Entity,
including nonhuman actors, and no required conscious intention.

Add reason content independently from its scoped attribution. Retain the selected
actor role/view, or an unresolved actor, without promoting source-only reports into
physical states. Consequence is the event's actual state difference when available;
it is not the same as a hoped-for outcome. Keep source speaker, operator authorship,
positive/negative evidence, proposal workflow and factual truth distinct.

This task adds a reusable draft package with the existing compiler. Frozen event
and responsibility packages, their instance profiles and historical reports stay
unchanged. No motive truth engine, normative effect or new Lean proof is requested.
