# Competency questions — Motivation Core

| Question | Representation | Current execution boundary |
|---|---|---|
| What prompts this actor's contribution? | Motive content plus MotivationHypothesis anchored to one view and optional actor RoleBinding. | Graph binding is a manual policy, not an object-schema check. |
| Can a machine, AI, community or storm be the actor? | Existing eventcore:Entity in its actor role; no human or intention gate. | Meaning remains a selected interpretation. |
| Can the actor be unresolved? | hypothesisActorRole absent, retaining a source-only view. | No synthetic Entity or narrator default. |
| Can there be several motives? | Multiple independent hypotheses for one view. | No uniqueness or exclusivity inference. |
| Can a motive be explicitly denied? | hypothesisNegativeSupport for that exact attribution. | Missing evidence is not denial. |
| Can accounts conflict? | Independent positive and negative support links. | Both are retained; no truth conclusion or explosion. |
| Who says I in a quoted reason? | SourceAssertion preserves speakerKey and source identity. | Speaker resolution/relevance is external. |
| Can an operator supply uncited reasoning? | OperatorMotivationSupport with declared author and rationale. | It does not become a source citation or authentication. |
| Does a motive prove an omission or fault? | contributionKind only states the interpreted contribution. | Duty/capability/exception/fault/response grounds stay separate. |
| Where is the actual consequence? | Known view -> recorded event -> supplied states -> optional exact Delta. | No invented snapshots or unknown-to-empty conversion. |
| Is the actor's desired outcome the result? | Not inferred; this draft introduces no Goal class. | A fine can be an unintended later consequence. |
| Does reviewed mean true? | MotivationReview is proposal workflow. | No existing instance profile admits motivcore nodes. |
