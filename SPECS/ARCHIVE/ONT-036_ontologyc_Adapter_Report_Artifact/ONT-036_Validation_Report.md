## Summary

ONT-036 adds a deterministic `ontologyc-adapter-report.yaml` emitted by
`ontologyc validate-specgraph`. The report binds existing SpecGraph validation
outputs to package identity, normalized IR `sourceDigest`, input/output refs,
summary counts, and explicit evidence-only authority flags.

The implementation preserves existing `validate-specgraph` stdout and existing
`concept-refs.yaml`, `ontology.lock.yaml`, and `ontology-gaps.yaml` outputs.
